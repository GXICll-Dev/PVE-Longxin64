## 12. 前端信息架构

全局导航：

~~~text
总览
云教室
模板与镜像
终端设备
任务中心
基础设施
自动化与策略
审计与设置
~~~

- **总览**：教室就绪率、上课状态、异常座位、离线终端、版本偏差和容量告警。
- **云教室**：课堂控制台、座位、终端绑定、桌面实例、策略和历史。
- **模板与镜像**：黄金模板、不可变版本、维护副本、灰度发布和回滚。
- **终端设备**：心跳、IP、架构、Agent 版本、座位和远程诊断。
- **任务中心**：父任务、单机结果、失败重试、日志和导出。
- **基础设施**：PVE 集群、节点、存储、网络和资源池，仅面向管理员。
- **自动化与策略**：课前预热、课后还原、并发、快照保留和更新窗口。
- **审计与设置**：用户、角色、凭据、操作审计和系统配置。

### 12.1 云教室详情

默认进入课堂控制台，而不是 VM 配置页。

必须分别展示：

1. 瘦客户机连接状态。
2. 虚拟桌面电源状态。
3. 模板版本合规状态。
4. 当前任务或维护状态。

主要区域：

- 顶部就绪摘要。
- 课前检查、整班开机、整班还原、下课收机等高频操作。
- 座位表格；座位图只作为辅助视图。
- 选中对象后的固定批量操作栏。
- 不离开筛选上下文的单座位详情侧栏。

### 12.2 危险操作 UX

- 按钮必须写准确动词和数量，例如“还原 32 台学生桌面”。
- “当前页”和“全部筛选结果”必须是两个明确范围。
- 强制停止放在优雅关机之后的次级入口。
- 大范围数据变更要求输入教室名或目标数量，并填写原因。
- 危险按钮不获得默认焦点。
- 禁用操作必须解释原因。
- 不能只用红色表示危险。

### 12.3 批量任务反馈

- Toast 只提示任务已创建、完成或需要关注。
- 详细结果放在跨页面常驻的任务抽屉和任务中心。
- 展示父任务进度、当前阶段和每台机器的结果。
- 支持只重试失败项、复制任务 ID 和导出结果。
- 刷新或断线重连后仍能恢复任务状态。
- 没有真实进度时显示阶段和完成数量，不伪造百分比或预计时间。
- 实时更新优先使用 SSE，并提供轮询降级。

## 13. 前端库选择

依据 pick-ui-library skill，采用以下默认映射：

| 任务 | 默认库 | 边界 |
| --- | --- | --- |
| Dialog、Popover、Menu、Select | Base UI | 负责无障碍、焦点和关闭行为 |
| 命令面板 | cmdk | 快速定位教室、机器和任务 |
| Toast | Sonner | 不承载批量任务详情 |
| 大型列表 | Virtuoso | 与服务端筛选、排序和分页配合 |
| 客户端全局状态 | zustand | 只存 UI 状态和用户偏好 |
| 条件样式 | clsx | 简单条件组合 |
| 组件变体 | cva | 按钮、标签等类型安全变体 |
| 实时曲线 | Liveline | 只用于流式指标 |
| 历史图表 | Recharts | 非实时趋势和统计 |
| 座位布局编辑 | dnd kit | 不替代主要表格操作 |
| 深浅主题 | next-themes | 技术栈兼容时使用 |

精选列表未覆盖但项目需要：

- TanStack Query：服务端状态、缓存和 Mutation。
- TanStack Table：复杂表格模型。
- noVNC：管理员应急控制台，由后端签发短期票据。

简单交互优先使用 CSS。首版不把 Motion 作为核心依赖；只有真实手势、可中断弹簧或复杂布局动画时才引入。

## 14. UI 与动效规则

依据 emil-design-eng skill，本项目是高频运维工具，动效必须克制：

- 搜索、表格选择、导航、快捷键和实时状态刷新不使用装饰性动画。
- 键盘触发的高频操作不播放开关动画。
- 按钮按下反馈为 100–160ms。
- Tooltip 和小 Popover 为 125–180ms。
- Dialog 通常为 180–220ms。
- 常规 UI 动效不得超过 300ms。
- 不使用 ease-in；进入使用强 ease-out，屏幕内移动使用 ease-in-out。
- 只动画 transform 和 opacity，避免动画 width、height、margin 或大型表格布局。
- Popover 从触发点出现；居中 Dialog 保持中心原点。
- 不为实时 CPU、内存数字或大型列表添加装饰性入场动画。
- 默认使用可中断的 CSS transition，不对动态 UI 滥用 keyframes。
- 完整支持 prefers-reduced-motion。
- Hover 动效必须限制到支持 hover 且具有精细指针的设备。

可访问性目标为 WCAG 2.2 AA：

- 所有功能均可使用键盘完成。
- 状态同时使用文字、图标和颜色表达。
- 焦点始终可见，Dialog 关闭后焦点返回触发元素。
- 图标按钮必须提供可读名称。
- 批量任务只播报汇总变化，避免逐台刷屏。
- 重要时间显示明确时区和绝对时间。

## 15. 性能规则

- 机器、任务和日志列表必须虚拟化。
- 筛选、排序、搜索和分页在服务端完成。
- 实时状态以对象级补丁更新，并把高频变化合并为约 250–500ms 一批。
- 不因后台数百台机器变化而重绘整个表格。
- 表格内不为每台机器持续绘制实时图表。
- noVNC、图表、长日志和高级基础设施页面按需加载。
- 搜索请求可取消并防抖；筛选条件保存在 URL。
- 只有可逆的标签和备注可使用乐观更新。
- 开关机、还原、删除和模板发布必须等待服务端任务确认。
- 数据断线或陈旧时明确显示最后更新时间。
